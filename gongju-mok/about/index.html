01 / CONCEPT

석사자의 선에서
공주의 풍경으로

출발점은 봉황동 석사자 두 점의 3D 스캔 데이터였습니다. 갈기의 반복되는 선, 머리의 둥근 곡선, 표면의 높낮이에서 길과 구릉을 떠올리고, 이를 공주목의 옛 지도와 지형으로 이어지는 시각적 장치로 삼았습니다.

Story에서는 마을 사람들의 시선으로 석사자를 만나고, Index에서는 실제 스캔 데이터를 직접 돌리고 확대하며 관찰합니다. 유물의 형태와 그 주변의 공간을 하나의 경험으로 연결하고자 했습니다.

형태가 풍경으로 이어지는 장면과 인물의 증언은 팀이 구성한 시각적 해석과 창작 서사입니다.

02 / PLANNING

초기 기획에서
현재의 구성까지

초기 기획안

어두운 공간에서 두 석사자를 마주한 뒤 얼굴과 갈기, 표면을 차례로 관찰하는 구상이었습니다. 그 선이 공주의 지형과 마을로 변하고, 각 인물의 이야기를 들을 때마다 관련 3D 데이터를 확인한 후 마을로 돌아오도록 계획했습니다.

구성을 다듬는 과정

석사자의 형태에서 공주의 공간으로 들어간다는 출발점은 유지했습니다. 제작 과정에서는 이야기를 따라가는 Story와 스캔 데이터를 살펴보는 Index로 경험을 나누고, 첫 화면과 마지막 장면의 연출을 구체화했습니다.

초기 기획과 현재 구성의 비교

이야기와 관찰인물 이야기 → 3D 데이터 확인 → 마을 복귀마을 이야기는 Story로, 형태 비교는 Index로 연결

레퍼런스 수집

지도·건축·인물·화면 사례를 모아 Blender, Higgsfield, UI 작업별로 분류했습니다.

04 · PROMPT

AI 프롬프트 설계

Blender·Higgsfield·Figma와 이미지 생성에 필요한 지시문을 단계별로 정리했습니다.

Blender 공간과 애니메이션

공주목 지형·건축물을 만들고, 카메라·인물·건물의 움직임과 스타일 프레임을 점검했습니다.

08 · WEB

UI와 웹 구현

Figma의 UI를 웹에 적용하고, Story 스크롤과 Index의 회전·확대·부위 비교 기능을 연결했습니다.
