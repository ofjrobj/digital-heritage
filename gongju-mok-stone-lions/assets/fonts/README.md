# KoPub World Light

This project uses the original KoPub World Batang Light and Dotum Light designs at weight 300. Copyright belongs to the Ministry of Culture, Sports and Tourism and the Korean Publishers Society; the fonts were designed by FONTRIX.

Official source pages (Korea Copyright Commission, Shared Content):

- [KoPub World Batang Light](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200023&wrtSn=13287214)
- [KoPub World Dotum Light](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200023&wrtSn=13287211)

The source TTF files were losslessly wrapped in WOFF2 for browser delivery. Glyph designs, advances, names, copyright metadata, and the full original character repertoire are retained. These replace an earlier 534-character subset that caused missing Korean letters to use a system fallback font. The same files are served from `about/assets/fonts/` for the project notes pages.

Redistribution and use remain subject to the original KoPub licence and the terms on the official source pages. The fonts are not sold separately.
