STORY

이동과 재생

  1. #01

    화면의 역할과 이동 경로

    Figma · HTML · CSS

    Figma에서 Story·Index의 이동 메뉴와 패널 위치를 설계했습니다. 상단 메뉴로 두 화면을 오가고, Story의 끝에서도 Index로 이어지도록 연결했습니다.

  2. #02

    입력으로 이동하고, 한 프레임에 정지

    JavaScript · HTML Video · Canvas 2D

    스크롤·드래그 입력을 영상의 재생 위치에 연결했습니다. 입력이 멈추면 도달한 원본 프레임에 고정하고, 그 프레임을 Canvas에 표시합니다.

  3. #03

    대사 패널과 음성 연결

    HTML Audio · JavaScript · CSS

    인물에 도착하면 반투명 대사 패널을 먼저 띄우고 음성을 재생합니다. 음성이 끝나는 시점에 패널을 닫고, 화면 크기에 맞춰 글자와 패널 크기를 조절합니다.

  4. #04

    장면에 맞춘 소리 제어

    HTML Audio · JavaScript

    음성·환경음·발소리를 각각 재생하고, 이동과 대화 상태에 따라 음량을 조절합니다. 음소거 버튼으로 함께 제어하며, 다른 탭으로 이동하면 재생을 멈춥니다.

INDEX

회전과 비교

  1. #05

    두 스캔을 웹의 3D 화면으로

    Three.js · GLTFLoader · DRACOLoader

    GLB 스캔을 불러와 수사자와 암사자를 각각의 3D 화면에 배치했습니다. 창 크기가 바뀌면 모델이 화면 안에 들어오도록 관찰 구도를 다시 맞춥니다.

  2. #06

    각 개체를 돌리고 확대하기

    Three.js · OrbitControls

    두 화면에 독립적인 조작을 연결했습니다. 드래그로 돌리고 스크롤이나 핀치로 확대하며, 조명은 고정해 표면의 굴곡을 살펴볼 수 있게 했습니다.

  3. #07

    같은 부위를 나란히 비교

    Three.js · JavaScript

    갈기·수염·무늬·이목구비·눈매를 선택하면 두 개체가 해당 부위를 보여주는 구도로 함께 이동합니다. 선택한 부위의 설명과 기록값도 연결했습니다.

  4. #08

    표면색과 굴곡을 번갈아 관찰

    Three.js · 재질 전환

    무채색 재질로 형태를 살펴보고, 버튼을 눌러 원본 표면색을 켤 수 있게 했습니다. 두 모드가 같은 스캔 형상을 사용해 색과 굴곡을 비교합니다.
