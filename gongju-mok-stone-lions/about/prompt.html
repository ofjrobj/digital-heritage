01 / ROLES

사람이 정할 것과 AI에 요청할 것

팀의 판단

출처와 역사적 해석의 범위, 두 석사자에서 보여 줄 특징, 이야기와 화면의 순서를 정합니다. 최종 결과가 유물의 형태와 기획 의도에 맞는지 선택하고 수정합니다.

AI와의 협업

정한 기준을 장면별 지시문으로 구체화하고, 이미지·영상의 후보와 웹 구현 코드를 만들고 수정하는 데 활용합니다. 입력 자료와 결과물을 연결해 다음 수정에 필요한 조건을 남깁니다.

02 / WORKFLOW

기획을 제작으로 옮기는 순서

  1. #01

    입력 자료 묶기

    자료조사, 공통 서체·색감·UI 기준, 무드, 인물 설정과 대사, 스토리보드, UX 설계를 한 장면의 제작 조건으로 묶습니다.

  2. #02

    고정할 조건과 바꿀 조건 나누기

    석사자의 형태, 인물의 옷차림, 건축 배치와 화면 비율은 기준으로 고정합니다. 시점·동작·빛·이동 속도처럼 장면마다 달라질 조건은 따로 적습니다.

  3. #03

    도구별 제작 지시로 변환하기

    Blender에서는 공간과 카메라 경로를 잡고, 이미지 생성에는 인물·배경·재질을, Higgsfield에는 기준 프레임과 시간에 따른 움직임을 전달합니다. Codex에는 화면 상태와 입력에 따른 동작을 전달해 웹으로 연결합니다.

  4. #04

    결과를 비교하고 다시 수정하기

    원본 유물과 기준 이미지, 이전·다음 장면을 함께 놓고 형태·구도·움직임의 연속성을 확인합니다. 웹에서는 Story의 재생과 Index의 회전·확대를 실제로 조작하며 수정합니다.
