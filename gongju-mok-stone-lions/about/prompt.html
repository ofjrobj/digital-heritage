03 / SCENES

장면별 구성과 제작

대화 장면은 인물 영상에 별도로 만든 음성과 대사창을 연결했습니다.

현재 Story의 14개 구간에 사용한 자료와 제작 도구
장면준비한 자료·화면 요소제작 내용·도구
01먹선에서 마을로석사자 먹선 일러스트, 산과 안개, 마을 전경, 도입 자막Higgsfield로 먹이 번지며 산과 마을이 드러나는 도입 영상 제작
02마을 입구 → 제금루입구와 제금루 구도, 길과 담장, 장사꾼 도착 장면Blender 공간·카메라 가이드를 바탕으로 Higgsfield에서 접근 영상 제작
03장사꾼의 이야기장사꾼 설정화와 짐, 제금루 배경, 얼굴 크기와 치켜뜬 눈매에 관한 대사Higgsfield 인물 영상 + ElevenLabs 음성 + 웹 대사창
04제금루 → 동헌관아 진입로와 마당, 동헌·혜의당, 농민의 위치Blender 동선을 참고해 Higgsfield에서 농민에게 다가가는 영상 제작
05농민의 이야기농민 설정화와 문서 보따리, 동헌 배경, 흐릿했던 이목구비가 드러나는 대사Higgsfield 인물 영상 + ElevenLabs 음성 + 웹 대사창
06동헌 → 객사동헌 출발 구도, 객사로 이어지는 길, 찬모 도착 구도Blender 공간을 참고해 Higgsfield에서 장소 사이의 이동 영상 제작
07찬모의 이야기찬모 설정화와 쟁반, 객사 배경, 정수리의 곱슬 갈기에 관한 대사Higgsfield 인물 영상 + ElevenLabs 음성 + 웹 대사창
08객사에서 민가 쪽으로 회전찬모 대화가 끝나는 구도, 주변 건물과 골목, 멀리 보이는 세 주민Higgsfield 회전 영상. 인물·건물 배치와 다음 접근 장면의 연결을 비교해 선택
09주민 삼총사에게 접근민가와 나무, 세 주민의 배치, 대화가 시작될 거리와 구도Higgsfield로 세 주민을 향해 걸어가는 접근 영상 제작
10주민 삼총사의 이야기세 주민의 설정화, 민가 배경, 웃는 표정과 뻗은 수염에 관한 대사Higgsfield 인물 영상 + ElevenLabs 음성 + 웹 대사창
11민가 → 뒷산마을에서 산으로 이어지는 길, 수목, 나무꾼 도착 구도Blender 동선을 참고해 Higgsfield에서 산길 이동 영상 제작
12나무꾼의 이야기나무꾼 설정화와 지게·도끼, 산길 배경, 산등성이를 닮은 털결에 관한 대사Higgsfield 인물 영상 + ElevenLabs 음성 + 웹 대사창
13석사자를 찾아가는 길산길에서 객사터로 돌아오는 동선, 두 석사자의 배치와 도착 구도Blender 공간·카메라 가이드를 바탕으로 Higgsfield에서 마지막 이동 영상 제작
