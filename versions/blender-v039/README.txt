관찰은 원본 3D 모델의 연속 카메라 이동으로 구현했습니다. 스크롤로 진행/되감기합니다.
전체 → 머리 훑기 → 줌아웃 → 입 주변 훑기 → 줌아웃 → 등 → 갈기 → 3초 대기 → 돋보기.
머리 10초/입 주변 12초에 대응하는 긴 스크롤 구간입니다. 실제 재생 속도는 사용자가 조절합니다.
표면 클릭 → 선·지형 전환 → 마을 진입 → 인물 에피소드 → 전체 마을 → 마지막 계절 영상.

인물·음성은 제작 대역입니다. 외부 이미지와 웹폰트는 온라인 자원을 사용합니다.
